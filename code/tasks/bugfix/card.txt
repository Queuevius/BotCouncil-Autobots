== TASK ==
updates_summary.py reads an updates post and prints one line per tag: how many entries carry it and the newest date. Running it on the sample crashes. This is what it printed:

$ python3 updates_summary.py UPDATES-sample.md
Traceback (most recent call last):
  File "updates_summary.py", line 36, in <module>
    print("\n".join(summary(parse(open(sys.argv[1]).read()))))
  File "updates_summary.py", line 19, in parse
    tags = [t.strip() for t in lines[0].split(":", 1)[1].split(",") if t.strip()]
IndexError: list index out of range

Background: entries written before tags existed have no "tags:" line; their first line is the From line, which holds the date. The rest of the Nexus files those entries under the tag "untagged".

Fix updates_summary.py so an entry with no tags line counts under the tag untagged, using the date on its From line, and everything else works as before. Keep the output format exactly as it is. Make the smallest change that fixes it, and don't change UPDATES-sample.md.

== DONE WHEN ==
python3 updates_summary.py UPDATES-sample.md runs without an error and prints one line per tag in the same format as before, with the old entry counted under untagged with its own date; entries that do have tags are counted as before; UPDATES-sample.md is unchanged.
