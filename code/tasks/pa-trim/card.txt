== TASK ==
Tony's threads each keep a "prompt accomplice": a public notes file that grows every session. Claude's web reader stops partway through big ones (PA-JOHN is already past that point), so build /work/pa_trim.py: a tool that moves the oldest middle sections of a prompt accomplice into the thread's archive file when it gets too big, without losing or changing a single character. Use only Python's standard library. /work/PA-BC.txt is a real one to test on (work on copies of it in /tmp, not the file itself).

How a prompt accomplice is built: a section starts at a line beginning with "== " (at the very start of the line). Anything before the first such line is the top and always stays.

python3 pa_trim.py PA_FILE ARCHIVE_FILE --max-bytes N [--keep-first K] [--date YYYY-MM-DD]
(--keep-first defaults to 1; --date defaults to today.)

1. If PA_FILE is already N bytes or smaller (counting UTF-8 bytes), change nothing, print "nothing to move", exit 0.
2. Otherwise: always keep the top, the first K sections and the newest (last) section. Move the oldest sections right after the first K, one at a time in order, until the file (including the note line in step 4) is N bytes or smaller, or nothing more can move. Move no more than needed.
3. Add to the end of ARCHIVE_FILE (make it if missing): a newline, then exactly this line, then a newline, then the moved sections exactly as they were:
   ----- archived DATE | from PA | file PA_FILE_NAME | tags: pa-trim -----
   where PA_FILE_NAME is just the file's name, e.g. PA-BC.txt.
4. In PA_FILE, where the moved sections were, put exactly this one line (with its newline):
   (Older sections moved to ARCHIVE_FILE_NAME on DATE.)
   where ARCHIVE_FILE_NAME is just the archive's file name, e.g. ARCHIVE-BC.md.
5. Write PA_FILE in place (open it and write to it; don't delete and recreate it).
6. Print one short line: how many sections moved, how many bytes, and the new size.
Running it again right away must change nothing (the file is now small enough).

== DONE WHEN ==
pa_trim.py brings PA-BC.txt under the size given, keeps the first and newest sections, moves only as much as needed, archives the moved text exactly with the marker line, leaves the note line, and a second run changes nothing.
