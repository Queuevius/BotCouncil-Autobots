== TASK ==
page.html is a small page with a text box and an Echo button. backend.py is its back end: every address under /api/ is one function listed in ROUTES, which takes the JSON the page sent (a dict) and returns a dict.

Add a word count feature, the same way Echo works:
1. In backend.py, a function for the address /api/wordcount, added to ROUTES. It takes {"text": "..."} and returns {"words": N}, where N is how many words are in the text (words are separated by any amount of spaces, tabs or new lines; an empty or missing text has 0 words).
2. In page.html, a button with id wordcount-btn (its label: Count words) and a place for the answer with id wordcount-out. Clicking the button sends the text box's text to /api/wordcount and shows the number in wordcount-out.

Only add lines: don't change or remove any line that's already in either file. Echo must keep working.

== DONE WHEN ==
