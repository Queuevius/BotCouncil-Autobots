== TASK ==
Build a small tool, /work/nxcode.py, that prints just one named block of Tony's back-end file, so AIs stop asking Tony to dig through a 5,000+ line file. Use only Python's standard library. Test it on /work/order-server.py (a copy with keys blanked). Don't change order-server.py.

How the file is built: it's made of blocks. A block starts at a heading line: a line whose text, after any leading spaces, starts with "# --- ". Some headings are indented. A line whose text (after leading spaces) starts with "# --- end" is NOT a heading; it closes the block above it.

What nxcode.py must do:
1. python3 nxcode.py NAME [FILE]
   FILE defaults to order-server.py in the same folder as nxcode.py. NAME is matched against the heading's words (the text after "# --- "), ignoring upper/lower case (a part of the heading is enough, e.g. "studio rename").
   Print the matching block: from its heading line down to just before the next heading line, or down to and including its "# --- end" line if one comes first, or down to just before the line starting "if __name__ == '__main__'", whichever comes first. Put each line's line number in front of it, then a tab.
   If no heading matches: print "no block matches NAME" and exit with code 1. If more than one matches: print each matching heading with its line number and exit with code 2.
2. python3 nxcode.py --list [FILE]
   Print every heading (not the "# --- end" lines) with its line number, one per line.
3. Hide secrets in everything it prints:
   - a quoted value assigned to a name containing PASS, PASSWORD, KEY, TOKEN or SECRET (any case) becomes [hidden]
   - anything shaped like sk-or-v1-..., sk-..., ghp_..., github_pat_... becomes [hidden]
   - internet addresses, both the 203.0.113.7 kind and the 2001:db8::7 kind, become [address hidden]
4. --copy (optional extra flag): if the xclip program exists, also copy the output to the clipboard; if it doesn't, just print.

Test it on real block names from /work/order-server.py before you finish.

== DONE WHEN ==
nxcode.py prints the right block with line numbers, lists headings, handles no match and several matches, and never prints keys or internet addresses.
